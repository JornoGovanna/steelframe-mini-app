# STEELFRAME Telegram Mini App

Адаптивный Telegram Mini App для строительной компании.

## Возможности

- Информация об услугах
- Калькулятор ипотеки
- Календарь застройщика
- Статистика компании
- Список объектов в работе
- Форма заявки через Telegram WebApp

## Запуск

Загрузите `index.html` на HTTPS-сервер и укажите его URL в настройках Web App бота.
